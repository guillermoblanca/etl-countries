# Spain Case Study — Static GitHub Pages Site

This folder contains the **static deployment** of the Spain Macroeconomic
Case Study, generated from the live Countries ETL Dashboard.

## What's here

- **`index.html`** — Fully self-contained report (~36 KB). No backend, no JS dependencies,
  no external CSS. Just open it in a browser.
- **`.nojekyll`** — Tells GitHub Pages to serve files as-is (skip Jekyll processing).

## Deploy to GitHub Pages

1. Commit and push this folder to your repo:
   ```bash
   git add docs/
   git commit -m "Add Spain case study static page"
   git push
   ```

2. In your GitHub repo, go to:
   **Settings → Pages**

3. Configure:
   - **Source**: Deploy from a branch
   - **Branch**: `main` (or whatever default)
   - **Folder**: `/docs`

4. Save. After 1–2 minutes, your page will be live at:
   ```
   https://<your-username>.github.io/<your-repo>/
   ```

## Regenerate the page

The HTML is generated from the live API. To regenerate with fresh data:

```bash
# 1. Make sure the API is running locally
docker compose up -d api

# 2. Run the build script
python scripts/build_case_study.py

# 3. Commit and push
git add docs/index.html
git commit -m "Refresh case study"
git push
```

The build script (`scripts/build_case_study.py`):
- Calls `GET /case-study/spain` on the local API
- Renders all narrative HTML with the data embedded inline
- Outputs to `docs/index.html` (no JavaScript runtime dependencies)

## Why static instead of live dashboard?

GitHub Pages serves only static files (HTML/CSS/JS), it cannot run Python or
PostgreSQL. The full dashboard requires the FastAPI backend + DB, so we cannot
host it on GitHub Pages directly.

The case study report, however, contains pre-computed data that doesn't change
frequently (60 years of historical macro data), so making it static makes sense
and gives you a fast, free, always-available portfolio piece.

If you want the **interactive dashboard** deployed somewhere, options are:
- **Render.com / Railway.app** — free tier with sleep-on-idle for backend
- **Fly.io** — generous free tier
- **Vercel + Supabase** — convert FastAPI to serverless functions
- **Local Docker** — `docker compose up` and share your local URL via ngrok

## Features of the static report

- 10 chapters covering Spain's macro story
- Mobile-responsive
- Print-friendly (Ctrl+P → PDF works perfectly thanks to `@media print` CSS)
- Anchored Table of Contents
- Pull quotes (Bloomberg/Economist style)
- Data tables with Spain highlighted
- All data sourced from World Bank Open Data + FRED + Eurostat

## Tech stack

- Pure HTML5 + CSS3 (no JS framework)
- Generated by Python script using `requests` + f-strings
- Total page weight: 36 KB (no images, no external resources)
- Loads instantly on any connection
